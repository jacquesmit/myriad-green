# Emergency Services Page Production Checklist

This checklist ensures the emergency-services.html page is fully production-ready and deployable.

## 1. Icon & Asset Rendering
- [ ] Font Awesome CDN is included in the <head> for all icons
- [ ] All icons render correctly on all devices

## 2. Floating Bar Safe Areas
- [ ] All emergency sections respect floating bar safe areas (no overlap/hidden content)
- [ ] Padding/margins are correct on desktop and mobile

## 3. Accessibility & Contrast
- [ ] All text meets WCAG contrast standards
- [ ] .emergency-info and .emergency-steps are readable on all backgrounds
- [ ] ARIA labels and keyboard navigation are present for all interactive elements

## 4. Responsive Layout
- [ ] Page is tested on mobile, tablet, and desktop
- [ ] All sections, buttons, and icons are accessible and visually correct

## 5. Links & Buttons
- [ ] Emergency call and callback links work
- [ ] Navigation links are functional
- [ ] All buttons are accessible (tab/keyboard)

## 6. Partials & Components
- [ ] All required partials are injected and render as intended:
  - [ ] Navigation
  - [ ] Social bar
  - [ ] Floating contact bar
  - [ ] Service cards
  - [ ] Service areas
  - [ ] FAQ
  - [ ] Testimonials
  - [ ] Footer
  - [ ] Scroll-to-top

## 7. SEO Optimization
- [ ] Meta tags and structured data are present
- [ ] All headings and alt attributes are correct

## 8. Performance
- [ ] CSS/JS is minified and bundled
- [ ] Page loads quickly on all devices

## 9. Cross-Browser Testing
- [ ] Chrome
- [ ] Firefox
- [ ] Edge
- [ ] Safari

## 10. Final Review
- [ ] User acceptance test (UAT) completed
- [ ] Stakeholder sign-off received

---

> Use this checklist to track progress and ensure nothing is missed before deployment.
